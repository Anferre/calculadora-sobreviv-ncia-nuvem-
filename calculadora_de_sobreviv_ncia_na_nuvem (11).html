⚖️ Matriz Comparativa: Google Cloud vs. AWS vs. Microsoft Azure

Entenda os pontos fortes, as cotas perpétuas e onde cada provedor cobra de surpresa.

Perfil: Servidor 24/7 Perpétuo

Google Cloud (GCP)

A melhor nuvem para manter um bot ou API no ar sem expirar. A cota da e2-micro é Always Free e não acaba após o 1º ano letivo.

Perfil: Sem Cartão de Crédito

Microsoft Azure

O Azure for Students oferece $100 de crédito anual usando apenas seu e-mail universitário (.edu) e possui trava nativa de $0 de gastos.

Perfil: Empregabilidade & Vagas

Amazon Web Services (AWS)

Líder em volume de vagas corporativas. Exige muita atenção com orçamentos (*AWS Budgets*) e desprovisionamento rigoroso de NATs e ALBs.

Recurso / Critério Google Cloud (GCP) AWS Microsoft Azure

Acesso Sem Cartão de Crédito ✅ BigQuery Sandbox (sem cartão) ❌ Cartão obrigatório na criação ✅ Azure for Students (e-mail .edu)
Vilão Financeiro Principal Cloud NAT & Cloud SQL NAT Gateway (~$32/mês) & ALBs Azure Bastion (~$28/mês)

🚀 Blueprints de Projetos Seguros

Arquiteturas validadas para você praticar no portfólio sem estourar limites.

Google Cloud • Júnior $0.00 Garantido

Bot Telegram / Discord 24/7 com Docker

Execute containers leves sem custos usando a VM `e2-micro` perpétua em regiões dos EUA com 30 GB de disco persistente.

⚠️ O que NUNCA fazer: Não ative Cloud NAT nem suba Cloud SQL. Instale o Postgres via Docker na própria VM.
AWS • Júnior $0.00 Garantido

Site Portfólio Jamstack Global com CDN

Hospedagem estática de React/Vue no S3 distribuída mundialmente com CloudFront CDN e certificado SSL gratuito via ACM.

⚠️ O que NUNCA fazer: Nunca coloque um Application Load Balancer (ALB) na frente de arquivos estáticos.
Google Cloud • Júnior $0.00 Sem Cartão

Pipeline de Dados & Análise com BigQuery

Crie dashboards no Looker Studio consumindo queries SQL no BigQuery Sandbox sem precisar cadastrar cartão de crédito.

⚠️ O que NUNCA fazer: Limite as consultas com partições para não estourar a cota de 1 TB/mês.
AWS • Pleno / FinOps < $15.00 / mês

Kubernetes EKS com Karpenter & Instâncias Spot

Cluster corporativo com escalonamento automático agressivo em nós Spot, reduzindo até 80% do custo computacional.

⚠️ Erro clássico de Plenos: Subir 3 NAT Gateways em Multi-AZ para ambiente de testes. Use 1 único gateway ou NAT instance.
Multi-Cloud • Sênior Alta Resiliência

Disaster Recovery Ativo-Ativo com Zero Egress

Orquestração combinando AWS e Google Cloud usando Cloudflare na borda e Cloudflare R2 para neutralizar as taxas de tráfego de saída.

⚠️ Ponto Crítico FinOps: Monitorar replicação cross-cloud para evitar cobranças de transferências intercontinentais.
