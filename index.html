Sobre este projeto

  
Ferramenta educacional e independente para quem está começando em nuvem.

  
O que é e para quem serve
    
A Calculadora de Sobrevivência na Nuvem ajuda iniciantes a estimar custos, configurar travas de orçamento, criar laboratórios com Terraform e Terragrunt e destruir tudo ao final. O fluxo tem quatro etapas: Planejar, Proteger, Provisionar e Destruir.

  
Como as estimativas são feitas
    
  • Custo mensal = preço por hora x 24 horas x dias ligados, em um mês de 30 dias.
    • 
    
  • Os valores são aproximados (região US East), compilados manualmente e não incluem impostos nem todos os itens de rede, como tráfego e processamento de dados.
    • 
    
  • Itens de free tier aparecem como zero, mas têm condições de região, tempo e uso que mudam com frequência.
    • 
    
  • O comparador usa fórmulas lineares didáticas. Não é cotação.
    • 
    
  • Data de referência dos valores: . Se a data estiver distante de hoje, trate os números como ordem de grandeza, não como preço.

    
Confirme sempre nas fontes oficiais:
    preços AWS,
    free tier AWS,
    preços Google Cloud,
    free tier Google Cloud,
    preços Azure,
    Azure for Students.

  
Privacidade
    
  • Não há contas, cookies de rastreamento nem ferramentas de análise nesta página.
    • 
    
  • Ficam salvos apenas no seu navegador (localStorage): cesta, orçamento, ajuste de câmbio, tema, progresso das trilhas e, se você informar, a chave da API Gemini.
    • 
    
  • A cotação do dólar é consultada em economia.awesomeapi.com.br.
    • 
    
  • Se você usar a IA com chave própria, o texto da pergunta ou da cesta é enviado à API do Google Gemini. Sem chave, tudo é respondido localmente.
    • 
    
  • Não use a chave em computador compartilhado. Você pode removê-la a qualquer momento.

  
Aviso importante
    
As informações são educacionais e podem estar desatualizadas. Este projeto não tem vínculo com AWS, Google ou Microsoft, e os nomes pertencem aos respectivos donos. Scripts e códigos de infraestrutura podem criar ou apagar recursos: leia, rode plan ou dry-run primeiro e use uma conta de laboratório. Você é responsável pelos custos da sua conta.

Travas de orçamento

  
Estimar ajuda; só alertas e travas evitam o susto. Faça isto antes de criar recursos.

  

    
AWS
  1. Billing → Budgets: orçamento de $1 com alertas em 50/80/100%.
  2. Ative Budget Actions para aplicar política IAM restritiva.
  3. Ative Cost Anomaly Detection.
  4. MFA no root; use IAM/SSO no dia a dia.
Budgets avisa; não desliga recursos sozinho por padrão.

    
Google Cloud
  1. Billing → Budgets & alerts com e-mails.
  2. Conecte o budget a um tópico Pub/Sub.
  3. Cloud Function desvincula o billing do projeto ao estourar.
  4. Um projeto por lab; delete o projeto ao final.
Desvincular derruba os serviços: use só em lab.

    
Azure
  1. Azure for Students: confira as regras de limite de gasto.
  2. Cost Management → Budgets com alertas.
  3. Tudo em rg-finops-lab.
  4. Fim: az group delete -n rg-finops-lab.
